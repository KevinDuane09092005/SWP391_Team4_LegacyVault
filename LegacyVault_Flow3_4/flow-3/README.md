# Flow 3 – Contacts and Assignments

Run `npm install && npm run dev`. Pure rule tests: `npm run test:logic`.

Multi-asset selection, per-beneficiary allocation, validation, and browser-local demo save. **No API write / no real email / no server-side verification.** Before integrating the Backend, see `../API_ALIGNMENT_REQUIRED.md` because the original OpenAPI only accepts a single asset and free-text allocations.
